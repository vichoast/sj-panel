# SJ Panel

App del panel de **Restaurant San José** para el celular de la familia: pedidos, menú del día, reparto, eventos y avisos.

- App: https://vichoast.github.io/sj-panel/
- **No se edita aquí.** El panel vive en [vichoast/menu-restoran](https://github.com/vichoast/menu-restoran) (`admin.html` y `assets/`). Este repo lo arma con `herramientas/armar-panel.sh` y lo publica solo, revisando cambios cada 10 minutos. Para publicar al tiro: pestaña **Actions** → "Armar y publicar SJ Panel" → **Run workflow**.
